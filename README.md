# 화면 녹화 프로그램 + 영상 편집기

반디캠을 쓰다가 불편했던 점을 제 방식대로 고쳐 보려고 만든 Windows용 녹화 프로그램(`Recorder.exe`)과, 녹화한 영상을 바로 자르고 붙이는 편집기(`Editor.exe`)입니다. 코드는 Claude와 함께 썼고, 무엇을 만들지와 어떻게 동작해야 하는지는 제가 정하고 직접 써 보면서 고쳤습니다.

## 무엇이 되나

**녹화 (Recorder, v0.5.x)**
- 모니터 전체 / 창 지정 / 영역 지정 녹화. 창 지정은 다른 창이 위에 겹쳐도 그 창만 찍히고, 창을 옮겨도 따라갑니다.
- 컴퓨터 소리와 마이크를 따로 녹음하고, 원하면 영상 안에 소리 트랙 3개(전체 / 컴퓨터 소리 / 마이크)로 저장합니다. 나중에 편집할 때 각각 크기를 조절할 수 있습니다.
- F12 / Shift+F12 전역 단축키, 트레이 아이콘, 녹화 중 빨간 테두리(영상에는 안 찍힘).
- 녹화 도중 프로그램이 꺼지거나 컴퓨터가 꺼져도 2초마다 복구 정보를 남겨 다음에 켤 때 자동 복구합니다.
- HDR 모니터 대응, 프레임 30/60/120, 시간 제한·워터마크 없음.

**편집 (Editor, v0.1.x)**
- 영상 넣기(합치기) → 나누기 → 구간마다 남기기/버리기 → 저장을 한 화면에서.
- 고속(다시 인코딩 없음, 키프레임 단위) / 정밀(정확한 위치, 재인코딩) 저장을 고를 수 있습니다.
- 구간별 소리 크기 조절, 미리보기에서 바로 들림.
- 남긴 구간의 시작 시간과 이름을 유튜브 챕터 형식으로 복사.

자세한 사용법은 [`사용법.txt`](사용법.txt)에 있습니다.

## 구조

```
src/        녹화 프로그램 (main.cpp, audio.cpp)   C++ / Win32 / WASAPI
editor/     영상 편집기 (editor.cpp, media.cpp, player.cpp)
res/, res_editor/   아이콘·매니페스트
test/       저장 엔진 테스트
build.sh, build_editor.sh   mingw-w64 크로스 컴파일 스크립트 (리눅스에서 Windows exe 생성)
ffmpeg_받기.bat   녹화·편집 엔진인 ffmpeg.exe를 내려받는 스크립트
```

영상 처리는 전부 [FFmpeg](https://ffmpeg.org/)가 합니다. `ffmpeg.exe`는 용량이 커서(약 160MB) 저장소에 넣지 않았고, `ffmpeg_받기.bat`을 실행하면 BtbN 빌드를 같은 폴더에 내려받습니다. FFmpeg 라이선스는 `ffmpeg_LICENSE.txt`.

## 빌드

리눅스(또는 WSL)에서 mingw-w64가 있으면:

```
./build.sh          # out/Recorder.exe
./build_editor.sh   # out/Editor.exe
```

실행 파일은 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜹니다. [추가 정보] → [실행].

## 왜 만들었나

녹화 프로그램을 쓰면서 컴퓨터 소리와 마이크를 나중에 따로 조절하고 싶었고, 녹화가 끊기면 영상 전체를 잃는 게 싫었고, 녹화한 것을 바로 잘라 올리고 싶었습니다. 하나씩 원하는 대로 만들다 보니 지금 형태가 됐습니다. 편집기는 아직 제가 쓰면서 확인하는 중이라 부족한 부분이 있습니다.
