녹화 프로그램 v0.5.0 + 영상 편집기 v0.1.0
==========================================

■ 처음 한 번만
1. ffmpeg_받기.bat 더블클릭 → "완료!"가 뜰 때까지 기다리기
   (녹화 엔진 ffmpeg.exe를 이 폴더에 내려받아요. 용량이 커서 따로 받아야 해요)
2. Recorder.exe 실행
   - 파란 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
   - 개인이 만든 프로그램이라 서명이 없어서 뜨는 경고예요

■ 소리 (3단계에서 추가)
- 컴퓨터 소리: [출력 장치] 버튼을 누르면 장치 목록이 나와요. 여러 개 체크하면 같이 녹음돼요
- 마이크: 체크하고 마이크 장치를 고르세요
- 크기 막대: 컴퓨터 소리 / 마이크 크기를 0~200%로 조절. 녹화 중에도 바로 적용돼요
- 마이크 체크를 끄면 마이크 소리가 빠져요. 녹화를 시작할 때 마이크가 켜져 있었다면 녹화 중에도 껐다 켰다 할 수 있어요
- 편집용 트랙도 따로 저장: 켜면 영상에 소리 트랙이 3개 들어가요 (1: 전체, 2: 컴퓨터 소리, 3: 마이크)
  일반 플레이어에서는 1번(전체)이 들리고, 편집 프로그램에서 2·3번을 따로 조절할 수 있어요

■ 창 지정 녹화 (4단계에서 추가)
- 녹화 대상에서 "창 지정"을 고르고, 목록에서 창을 고르거나 [창 고르기]를 누른 뒤 녹화할 창을 클릭
- 그 창만 녹화돼요. 다른 창이 위에 겹쳐도 안 찍히고, 창을 옮겨도 따라가요
- 고른 창은 프로그램 이름(예: chrome.exe)으로 기억해서, 그 프로그램을 다시 켜도 자동으로 찾아요
- 녹화 중에는 창 둘레에 빨간 테두리가 따라다녀요 (영상에는 안 찍혀요)
- 창이 최소화돼 있으면 녹화를 시작할 수 없어요
- 전체화면으로 도는 프로그램은 "모니터 전체"로 녹화하세요 (창 지정은 창 모드용)

■ 단축키
- F12 / Shift+F12는 "전역 단축키"로 등록돼서 다른 프로그램이 앞에 떠 있어도 먹어요
- 그래도 전체화면 프로그램에서 안 먹으면 "관리자 권한으로 실행"을 켜세요 (확인 창은 처음 한 번만, 창 제목에 "(관리자)" 표시)
- 반디캠처럼 F12를 쓰는 다른 프로그램이 켜져 있으면 등록이 안 될 수 있어요 (창 아래 상태줄에 안내가 떠요)

■ 영역 지정 녹화 (2단계에서 추가)
- 녹화 대상에서 "영역 지정"을 고르고 [영역 그리기] → 화면이 어두워지면 드래그해서 사각형 그리기
- [1920×1080] [1280×720]: 그 크기의 사각형이 마우스를 따라다녀요. 원하는 곳에서 클릭하면 놓여요
  방향키로 1픽셀씩(Shift+방향키는 10픽셀씩) 옮길 수 있고, Enter나 클릭으로 확정해요
  사각형 위에 크기와 위치(모니터 왼쪽 위 기준)가 표시돼요
- Esc 또는 오른쪽 클릭: 취소
- 그린 영역은 저장돼서 다음에도 그대로 써요. F12를 누르면 그 영역으로 녹화돼요
- 영역은 모니터 하나 안에서만 그릴 수 있어요
- 영역을 지정해 두면 테두리가 계속 보여요: 대기 중 파랑, 녹화 중 빨강
- 대기 중(파랑)에는 테두리의 변이나 모서리를 잡고 끌면 크기를 바꿀 수 있어요 (오른쪽 클릭: 취소)
  녹화 중(빨강)에는 잡히지 않아요
  (영상에는 안 찍히고 클릭도 통과해요. "영역 테두리 표시"를 끄면 안 보여요. "모니터 전체"로 바꾸면 사라져요)
- "모니터 전체"를 고르면 예전처럼 모니터 전체를 녹화해요

■ 사용법
- F12 또는 [녹화 시작] 버튼: 녹화 시작 / 정지하고 저장
- Shift+F12 또는 [일시정지] 버튼: 일시정지 / 이어서 녹화
- 누르는 즉시 표시와 타이머가 바뀌어요
  (녹화 엔진이 켜지는 0.5초 정도는 영상 맨 앞에 잠깐 멈춘 화면으로 남을 수 있어요)
- 녹화 중에는 화면 오른쪽 위에 빨간 점과 시간이 보여요 (영상에는 안 찍혀요)
- 작업표시줄 오른쪽 아래(시계 옆) 동그라미 아이콘
    더블클릭: 창 열기 / 오른쪽 클릭: 메뉴 (녹화, 일시정지, 녹화 폴더 열기, 마지막 녹화 영상 편집, 종료)
- 저장 위치: 동영상\내 녹화 (창에서 [변경] 가능)
- 저장 영역의 체크박스
    "녹화를 시작하면 이 창을 트레이로 숨기기": 켜면 녹화 중에 창이 사라져요
    "저장되면 오른쪽 아래에 알림 띄우기": 끄면 저장 알림이 안 떠요
- 소리 싱크: 영상에서 소리가 늦으면 "앞당기기" 값을 키우고, 소리가 빠르면 줄이거나 "늦추기"로
  (기본 60ms 앞당기기)
- 저장 알림을 누르면 저장된 폴더가 열려요
- HDR 모니터는 모니터 목록에 "HDR"이 표시돼요. 그냥 녹화하면 조금 밝게(하얗게) 나와요
  "HDR 모니터는 녹화 중 HDR 끄기"를 켜면 색이 정확하게 나오는 대신, 녹화 시작/정지 때 그 모니터가 잠깐 깜빡여요
- 프레임: 30 / 60 / 120 중 선택. 녹화하는 프로그램의 화면 주사율과 같은 값으로 맞추면 가장 부드러워요
- 시간 제한 없음, 워터마크 없음
- 창의 X를 누르면 프로그램이 완전히 꺼져요 (녹화 중이면 저장할지 물어봐요)
- 다시 켜면 마지막에 있던 위치에서 열려요 (그 모니터가 없으면 가까운 화면 안으로 맞춰요)

■ 영상 편집기 (v0.5.0에서 추가)
여는 방법
- 녹화 프로그램 창의 [편집기] 버튼, 또는 트레이 아이콘 오른쪽 클릭 → "마지막 녹화 영상 편집"
  → 마지막으로 녹화한 영상이 바로 들어간 채로 열려요
- 편집기프로그램 폴더의 Editor.exe를 직접 실행해도 돼요 (ffmpeg.exe는 녹화 프로그램 폴더 것을 같이 써요)

영상 넣기 (= 합치기)
- [파일 추가](여러 개 선택 가능) 또는 영상 파일을 창에 끌어다 놓기
- 여러 개를 넣으면 넣은 순서대로 뒤에 이어 붙여져요

나누기
- 타임라인을 클릭하거나 끌어서 위치를 고르고 [여기서 나누기 (S)] 또는 S 키
- 나눈 구간의 이름은 빈칸이에요. 목록에서 이름 칸을 "더블클릭"해야 입력할 수 있어요 (한 번 클릭으로는 안 바뀌어요)

남기기 / 버리기
- 목록의 체크박스: 체크 = 남김, 체크 해제 = 버림 (타임라인에서 회색 빗금)
- [▲][▼]: 구간 순서 바꾸기 (완성 영상 순서도 바뀜)
- [다음 구간과 합치기]: 같은 영상에서 바로 이어지는 구간끼리 다시 하나로 (이름은 앞 구간 것만 남아요)

소리 크기
- 위쪽 막대 2개: 전체 기본값 (컴퓨터 소리 / 마이크, 0~200%)
- 아래쪽: 목록에서 구간을 고르고 "이 구간만 따로 조절"을 켜면 그 구간만 다른 크기
- 막대를 움직이면 미리보기에서 바로 바뀐 크기로 들려요
- 편집용 트랙(3개)이 없는 영상은 "소리" 하나만 조절돼요

재생 / 이동
- Space 재생/정지, ←/→ 1초, Shift+←/→ 1프레임, Home/End 처음/끝
- 미리보기 화면을 클릭해도 재생/정지
- 타임라인: 클릭/끌기 = 이동, Ctrl+휠 = 확대/축소, 휠 = 좌우 이동
- "남긴 구간만 재생"을 켜면 버린 구간은 건너뛰고 재생해요

구간 목록 복사 (유튜브 챕터용)
- [구간 목록 복사] → 남긴 구간의 시작 시간과 이름이 복사돼요. 시간은 "완성된 영상" 기준이에요
    0:00 1팀
    8:42 2팀
- 이름이 빈 구간은 시간만 들어가요

저장
- 하나의 파일로: 남긴 구간을 이어서 한 파일로
- 구간마다 따로: 이름_01_구간이름.mp4, 이름_02.mp4 … 식으로 여러 파일
- 고속(기본): 다시 인코딩하지 않아서 빠르고 화질이 그대로예요
    대신 잘리는 위치가 바로 앞 키프레임(최대 2초 앞)으로 당겨져요 → 타임라인의 주황색 표시가 실제로 잘리는 곳
    다른 해상도/소리 트랙 수가 다른 영상을 하나로 합칠 때는 정밀 모드로 바꿀지 물어봐요
- 정밀: 나눈 위치 그대로 정확히 잘라요. 다시 인코딩해서 조금 오래 걸려요 (그래픽카드 NVENC 사용)
- 편집용 트랙 유지: 켜면 저장한 영상에도 소리 트랙 3개(전체/컴퓨터 소리/마이크)가 그대로 들어가요
- 저장 중에는 [저장하기]가 [취소]로 바뀌어요
- 고속/정밀, 저장 방법, 창 위치는 다음에 켤 때 기억해요

■ 테스트 체크리스트 (12차, 편집기 v0.1.0)
[ ] 1. 녹화 프로그램 창 제목이 "녹화 프로그램 v0.5.0"이고, 저장 칸에 [편집기] 버튼이 있나요?
[ ] 2. [편집기]를 누르면 "영상 편집기 v0.1.0" 창이 마지막 녹화 영상이 들어간 채로 열리나요?
[ ] 3. Space로 재생하면 화면과 소리가 같이 나오나요? (소리가 늦거나 끊기지 않나요?)
[ ] 4. 재생 중에 컴퓨터 소리 / 마이크 막대를 움직이면 바로 소리 크기가 바뀌나요?
[ ] 5. 나누기(S) → 체크 해제 → 이름 더블클릭 입력 → [구간 목록 복사] 후 메모장에 붙이면 예시처럼 나오나요?
[ ] 6. 고속으로 저장한 영상, 정밀로 저장한 영상이 둘 다 잘 재생되나요?
[ ] 7. 탐색기에서 영상 파일을 편집기 창으로 끌어다 놓으면 들어가나요?

■ 녹화가 끊기거나 저장이 안 됐을 때 (v0.5.3)
- 녹화 중에 영상 기록이 멈추면(12초 동안 파일이 안 커지면) 알아서 이어서 녹화해요.
  정지하면 조각들을 영상 하나로 합쳐 저장해요. 끊긴 순간 10~15초 정도만 빠져요.
- 녹화 대상 창을 최소화하면 기다렸다가, 창이 다시 보이면 이어서 녹화해요.
- 녹화 도중 컴퓨터가 꺼지거나 프로그램이 강제로 꺼져도, 녹화 중인 파일은 2초마다
  복구 정보가 같이 저장돼요(반디캠 .bfix 같은 역할). 프로그램을 다시 켜면
  저장 폴더에 "날짜 시간_복구.mp4"로 자동 복구돼요.
- 이런 일이 생기면 %APPDATA%\녹화프로그램\stop_problems.log 에 기록이 남아요.
  ffmpeg_lost_숫자.log 파일과 같이 알려주시면 원인을 찾을 수 있어요.

■ 문제가 생기면
아래 파일 내용을 복사해서 알려주시면 돼요.
  - 주소창에 %APPDATA%\녹화프로그램 입력 → ffmpeg_last.log, last_command.txt
  - 편집기 문제면 같은 곳의 editor_ffmpeg.log, editor_last_command.txt, editor_preview.log

■ ffmpeg 직접 받는 방법 (bat이 실패했을 때)
1. https://github.com/BtbN/FFmpeg-Builds/releases 접속
2. ffmpeg-master-latest-win64-gpl.zip 다운로드
3. 압축 풀고 bin 폴더 안의 ffmpeg.exe를 이 폴더(Recorder.exe 옆)에 복사
